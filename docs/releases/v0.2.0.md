# XXL-JOB 0.2.0

Release date: 2026-10-28. Author-owned unsigned release; official DBX Store review, signing and listing are separate steps.

## Changes

- Exposes 13 existing service tools on the built-in AI and external MCP surfaces.
- Exact per-tool manifest declarations: read=6, write=2, full=5; meaningful toolsets and portable argument schemas.
- Side-effect-free discovery; host-bound lifecycle identity/authentication/runtime; no model-controlled connection credentials or routing.
- Preserves readonly policy, explicit confirmations, existing service validation and request outcome semantics. The adapter does not grant access automatically.
- Masks recognizable credentials and bounds tool output. Redacted/opaque export previews are diagnostics, not full-fidelity backups; the original UI is unchanged.

## Local Validation

- Complete backend tests, race tests and vet pass. Applicable frontend tests/build and package metadata checks pass.
- Exact upstream manifest Schema, archive checksums, entrypoints and embedded CPU architecture pass for every published target.
- Native macOS ARM64 package probes and installed `dbx-mcp 0.4.134` isolated-host integration pass: exact discovery, access ceilings, readonly calls, cross-connection/readonly denial and immediate revocation. No fixture mutation endpoint was reached. This is development registry registration, not Desktop package-installer/signature acceptance.
- Local fixtures do not establish production-service acceptance; non-native operating-system runtime execution remains unverified.

## Compatibility And Authorization

Use matching updated DBX Desktop and standalone MCP builds implementing the tool declaration contract (reference: DBX upstream `8c2bbe35b`). The pre-existing engine floor is retained, not a guarantee for older hosts. Enable the plugin and authorize its connection/tool scope in MCP settings; new or elevated non-read tools remain subject to the host's acceptance and call-safety policies. Existing saved grants are never changed by these packages.

## Assets

Packages live under the immutable `v0.2.0` source tag. Choose the matching operating system/CPU and verify `SHA256SUMS-v0.2.0.txt`. Packages are unsigned author candidates, not officially signed Store artifacts. Previous release tags and bytes are not overwritten.
